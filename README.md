# Social Network Analysis

A10. Author Collaborator Finder (ArXiv Co-auth) 

Dataset: ca-* collaboration graphs (e.g., ca-HepTh). 

Goal: Suggest potential co-authors in a field. 

Methods: 2-hop proximity; community overlap; link prediction. 

Deliverables: suggestion list + justification paths. 

Ref: Stanford Network Analysis Data: https://snap.stanford.edu/data
